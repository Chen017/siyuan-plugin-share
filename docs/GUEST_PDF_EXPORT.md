# 访客 PDF 与批量导出

已授权访问分享页的访客打开文档后，可点击标题右侧、与「源码」并列的「导出 PDF」，无须登录管理员账号。未打开文档时不显示该按钮。支持单篇、某篇及其子文档、整个分享范围、勾选多篇。批量导出合并为一份 PDF，每篇从新页开始；不生成多个 PDF 的 ZIP 包。

打开预览后点击「保存为 PDF」，在浏览器打印窗口选择「另存为 PDF」。可调整纸张、缩放和边距；需要彩色背景时启用背景图形。浏览器对自动下载 PDF 的支持不一致，因此使用原生打印窗口确认保存位置。

## 生成方式与排版

采用受控服务端整理与浏览器生成相结合的方式。PHP 负责权限、范围选择、限流、附件地址改写和打印页面；浏览器复用本站 Markdown、KaTeX、代码高亮和图表渲染器生成 PDF。服务器不启动 Chromium，不运行 PDF 转码队列，不存储访客 PDF，也不向外部服务发送整篇文档。

导出预览等待 Markdown 渲染、字体、图片和异步图表后才开放保存按钮，最长等待约 25 秒。未加载的图片或图表会提示访客检查预览。打印样式使用白底，隐藏导航与代码复制按钮，保留文字、公式和 SVG；表格重复表头、代码长行换行。合并时为标题和脚注生成独立的锚点。

无论阅读页或系统选择浅色还是深色主题，导出预览与 PDF 固定使用白底、深色正文及适合白底的表格、引用和代码高亮配色。不会把深色阅读主题的黑底或浅色文字带入 PDF；原始图片与 SVG 图表的内容颜色保留。

过宽的公式、无法拆分的表格行和嵌入式视频/网页仍可能受浏览器打印能力限制，可通过横向纸张或缩放调整。图片和图表应先在预览中确认；远程图片及原有图表渲染器使用的远程服务仍受网络与浏览器跨域策略影响。

## 权限

- 所有范围均以当前 `share_id` 为边界；不查询原始思源笔记本中的未分享内容。
- 密码验证沿用分享访问会话；准备页面与保存前都检查密码当前签名、有效期、访客上限和删除状态。
- 预览凭据只属于当前会话和分享，不能交给另一个会话使用。附件继续通过原有受保护的 `/s/{slug}/res/` 路由读取。
- 响应使用 `private, no-store`，不生成永久下载链接或公开临时文件。

分享权限控制服务器的后续取数和应用内保存操作。访客已经读到的内容、已有 PDF 或浏览器菜单中的本地打印无法远程撤回。

## 默认保护与配置

在 **管理员后台 → 站点设置 → 访客 PDF 导出**，常用界面只显示导出开关、统计时长（分钟）和允许次数。默认 **60 分钟内 5 次**，可直接使用。

IP 和浏览器指纹各自累计请求，但共同使用一个次数上限，任一用完都拒绝。不是按“IP + 指纹”的组合分配新额度：同一浏览器在同一 IP 导出 5 次后，只换 IP 仍受指纹限制，只换浏览器仍受 IP 限制；两者都更换才按新访客计数。窗口过去后恢复额度。

并发、批量、预览有效期、内容 / 图片 / 附件预算、服务器整理时间和内存等保护参数已经预设，通常无需修改，默认收起在「高级设置」内；其中也可管理可信代理。点击「保存 PDF 导出设置」后直接生效，无须修改 PHP 文件、重启或重新构建。

设置存放于现有 SQLite，只有管理员通过页面验证后可以修改。该表单独立保存，不会覆盖同页的注册、邮件等站点设置。所有字段先校验再整体保存，无效值不会部分写入；重复初始化保留已保存的配置。升级时，旧版未修改的默认频率迁移为 1 小时 5 次；旧版更严格的自定义次数及自定义窗口会保留，旧版两个次数字段被一个统一字段替代。`php-site/config.php` 只提供第一次初始化时的默认值，之后以后台配置为准。

为保留资源保护，不能以 0 取消限制。统计时长允许 1 至 1440 分钟，次数允许 1 至 10 次。高级设置的容量以 MiB 填写，服务器内部换算为字节。默认值如下，资源项目的默认值同时也是可配置上限（内存最低 16 MiB）：

| 配置 | 默认限制 |
| --- | --- |
| `window_seconds` | 滚动窗口 3600 秒，后台显示 60 分钟 |
| `requests` | IP 与浏览器指纹共用每窗口 5 次的限制 |
| `max_concurrent` | 全站同时最多 4 个预览 |
| `lease_seconds` | 预览凭据最长 180 秒 |
| `max_docs` | 每批 30 篇 |
| `max_markdown_bytes` | 每批源内容 2 MiB |
| `max_html_bytes` | 每批 HTML 与源码合计 8 MiB |
| `max_asset_bytes` | 所选文档关联附件及共享附件合计 50 MiB |
| `max_images` | 每批 200 张图片 |
| `max_execution_seconds` | 单次服务器整理 15 秒 |
| `max_memory_bytes` | 单次服务器整理 128 MiB，已有更低限制继续生效 |
| `max_window_events` | 全站每个窗口最多 20,000 次 |

同一 IP 或指纹同时只能保留一个预览；关闭预览、关闭打印窗口时主动释放名额，异常关闭后由凭据超时回收。次数按准备请求计数，内容过大或范围无效的请求也占用次数；并发已满、权限或 CSRF 检查失败不分配预览。浏览器在打开预览前计算粗粒度属性的 SHA-256 指纹，不收集 Canvas、字体清单或生成长期追踪标识。不支持 Web Crypto 时使用统一降级标识并结合 User-Agent 限制；独立 IP 限制始终保留。指纹可被伪造或变化，只作为辅助信号。

限流事件与预览凭据存放于现有 SQLite，不占用 PDF 文件存储空间；使用写事务原子检查次数与并发，跨 PHP 进程生效。每次准入清理窗口外事件及过期凭据，窗口内事件数、单次 PHP 整理时间和内存遵守后台配置及上述安全上限。未完成整理的任务在退出时释放凭据。

### 反向代理 IP

默认只使用 `REMOTE_ADDR`，忽略客户端自行填写的 `X-Forwarded-For`、`X-Real-IP` 和 `CF-Connecting-IP`，避免伪造地址绕过限流。IPv6 同一 `/64` 共用 IP 配额。

如有反向代理，请展开后台 PDF 设置的「高级：反向代理真实 IP」，将实际直连 PHP 的代理 IP 填入可信代理列表（每行一个或逗号分隔，最多 32 个），选择代理**覆盖写入**的 `X-Real-IP` 或 `CF-Connecting-IP` 请求头。只接受精确 IPv4 / IPv6 地址；不接受网段、通配符或域名。代理必须清除客户端同名头、只写入真实单个地址，不要直接转发。未配置时所有经过同一代理的访客共用该代理的 IP 配额；宁可保守限流也不信任任意请求头。配置 Docker 时需确认 PHP 实际看到的对端地址，不能照抄其他环境的 IP。

## 验证与交付

执行 `python tests/run.py --php /path/to/php` 可运行现有回归和导出权限、范围、限流、凭据、资源限制测试。PHP CLI 模式额外以 8 个并行进程验证全站并发上限为 4。

使用已有 Playwright 和 Chromium/Edge 时，增加 `--browser` 可检查访客操作、公式、本地图片、表格、代码、Mermaid、合并锚点和实际 PDF 输出。可通过 `SIYUAN_PLAYWRIGHT_MODULE` 指定 Playwright 模块，`SIYUAN_BROWSER_EXECUTABLE` 指定浏览器；测试样例在 `.test-output/`，使用临时数据库与附件。测试本身不构建或部署应用。Nginx 专属测试只在已有容器镜像模式下执行。

当前仓库 `main` 的 push 会自动构建并部署，`beta/**` 的 push 和 Pull Request 会触发包含镜像构建的回归工作流。需要「仅推送，不构建和部署」时，应推送到不匹配这些触发器的功能分支，并暂不创建 Pull Request、不推送发布标签。
