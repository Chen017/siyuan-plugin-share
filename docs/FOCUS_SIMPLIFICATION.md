# 管理员专用笔记站精简

管理员专用版本移除与笔记阅读无关的服务，同时保留同步、权限、PDF 和必要自定义配置。发布到主分支前先完成隔离测试；旧库迁移部署保留可恢复备份并核对核心数据指纹。

## 删除的模块

- 访问统计：开关、保留天数、PV/UV、来源与地域、日志、筛选分页、采集和缓存。
- `/admin-home`、KPI、所有管理统计图表、实例统计查询与心跳。
- 邮件系统与 PHPMailer：SMTP、邮箱验证码、邮件找回密码、邮箱换绑、评论通知。
- 公开注册、普通验证码，以及公告、举报、违禁词和扫描的界面、业务、接口、专属设置与历史数据。
- 评论及回复、编辑、删除、图片上传、后台评论管理和专属前端脚本样式。
- 多用户管理、普通账号的网页登录流程、后台二次“管理员入口”。
- 手动分片清理和全站“删除所有数据”入口与接口。
- ICP、联系邮箱配置及展示。上游 release 检查与新版提示已移除。

## 保留的模块

- 管理员密码登录、退出与不依赖邮件的改密；管理界面只有 Notes、Site settings、Password 三项导航。
- 笔记与分享链接、Markdown、文档树、搜索、附件权限、同步、快照、增量同步、上传分片与自动临时清理。
- 分享密码、有效期、访客上限、独立访客身份；访客上限不再查询统计日志。
- PDF 导出及其独立验证码、Cookie 身份、额度、并发与资源保护。
- 存储额度与文档/附件占用；已删除分享沿用原来的有效占用规则。
- 网站地址/分享前缀、Reader home URL、HTML Head、自定义 CSS/JS 的开关、输入、帮助与注入。
- 英语 Home / Return to home 按钮；同一分享根内（含子文档、查询与锚点）隐藏。
- 维护者与上游署名。已有用户记录仅作为管理员及笔记归属、原 API key 的兼容基础保留，不提供普通用户网页登录或账号管理。

## 数据迁移

`legacy-cleanup.php` 是一次性、可重复调用的旧库升级：

1. 在清理统计表前，将旧日志中的访客合并到 `share_visitors`，不重置已占用的访客名额。
2. 删除退役模块的表、专属列、设置和 release 缓存；不删除或重新分配笔记、分享链接及归属记录。
3. 旧评论上传文件仅在没有任何笔记或其他附件记录引用时删除；被笔记引用的旧链接继续可用。
4. 按现存文档和附件重新计算分享与账号的存储占用；PDF 设置和数据不变。

迁移在启用新代码、首次初始化数据库时执行，以 `admin_only_schema_v1` 标记完成。开发测试只使用临时数据库与合成附件。测试使用十二篇合成笔记验证链接、正文、归属、附件、访客限制与存储重算，测试不等于访问或修改用户实际的十二个笔记本。

## 本地验证入口

```powershell
python tests/run.py --php <PHP 8.3 executable>
node tests/frontend.cjs
node tests/reader-ui.cjs
```

PHP 测试复制源码并使用独立数据库、上传目录；`tests/legacy-migration.php` 验证旧库清理与幂等性。删除的路径按 GET/POST 检查 404；保留的分享访问、同步、增量与分片、PDF 权限/额度/独立验证码继续回归。当前仓库已恢复完整的 `tests/pdf_cookie.py`，直接运行仓库测试文件。

Docker Nginx、完整浏览器 PDF 套件和长文 PDF 下载须有对应环境后单独运行。本地界面验收只使用合成内容。

精简阶段的历史本地验收：46 个 PHP 用例中 43 个通过、3 个跳过；60 项运行时检查通过。前端与阅读交互套件通过。浏览器完成合成单篇 PDF 下载冒烟检查，界面提示已启动 1 个独立下载、额度由 120 变为 119；当时未完成完整浏览器 PDF 套件或下载文件内容检查。后续清理的验证记录见 [cleanup audit](CLEANUP_20261027.md)。

## 上线核对

主分支自动部署检测 `admin_only_schema_v1`。首次执行精简迁移前，先使用 `backup-data.sh` 保存数据库、上传文件、配置和旧镜像，并验证归档可恢复；后续普通部署沿用既有备份策略。切换时停止旧容器的写入，再以 `data-snapshot.php --core-only` 比较迁移前后笔记正文、分享 URL、归属/API key、已有访客、保留配置和引用附件的实际 SHA-256，确认一致及外键完整后才宣布部署成功。备份与详细指纹留在服务器私有目录。

部署保护另由 `tests/deploy-guard.py` 执行真实工作流 Shell 的隔离模拟：备份进程失败时必须在停止服务或切换版本前退出。运行镜像元数据缺失时，备份脚本先从容器文件系统与运行配置生成可恢复镜像，再进行数据归档和恢复校验。
