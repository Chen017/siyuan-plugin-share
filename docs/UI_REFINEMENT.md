# 阅读与个人后台界面

这轮改造以自然、精致、克制为目标，遵循 [Apple Motion 指南](https://developer.apple.com/design/human-interface-guidelines/motion) 中“动效服务于反馈和理解”的原则。这里的时间与曲线是本项目的 web 设计值。

## 阅读

- 系统字体、统一的中性色表面与蓝色操作色；保持中文、English、数学公式和代码各自的排版规则。
- 统一侧栏、分段选择、工具栏、欢迎页、登录页与触摸区域；320px 窄屏不产生页面横向溢出。
- 文档切换只对变化的区域做短暂过渡；慢请求在 250ms 后提供进度反馈，快请求不闪动加载条。
- Source / Preview 按钮保持宽度；根滚动条预留空间固定，打开弹窗时不产生第二个滚动容器。PDF 渲染 iframe 不应用阅读页的滚动条预留。
- 脚注在鼠标停留 350ms 后打开，离开 240ms 后关闭；可以移入卡片阅读、点击保留或固定。短内容使用自然高度。Escape、导航和滚动会取消不再需要的悬停预览，键盘关闭会恢复焦点。
- 小屏 PDF 导出使用底部 sheet；桌面使用居中对话框。
- CSS 与 JavaScript 都遵循 Reduced Motion。首次正文直接可见，不等待装饰入场；没有新增动画库、持续帧循环或滚动视差。

## 个人后台

- 三项导航移到顶部；用户名使用普通文本，退出使用统一的按钮规则。内容背景与页脚使用同一画布。
- 日常列表只显示分享、访问状态、到期时间、大小及管理操作。小屏按信息卡呈现。
- `Delete` 表示可恢复的删除，已删除列表支持恢复及永久删除；永久删除仍需要确认。
- `/admin/share?share_id=…` 提供标题、链接后缀、到期时间、密码重设与移除保护。空到期时间代表永不过期。
- 现有密码只有不可逆 hash，无法恢复原文。新密码输入支持显示 / 隐藏，不在后续页面回显。
- 后台与插件复用 `save_share_access()` 和链接校验；版本检查拒绝过期表单，旧同步任务不能覆盖较新的访问设置。修改访问设置保留原有内容归属。
- 插件同步认证仍保留，连接设置移入网站设置页的折叠区域；日常分享列表不显示 API Key 管理。
- CSS / JS 开关改为紧邻标签的独立选择行；保留存储限制和 PDF 资源设置。

## 验证

- PHP 8.3.36：58 项运行检查；58 项回归用例中 55 项通过、3 项因本轮没有 Docker / 完整 PDF 浏览器执行环境而跳过。
- `tests/reader-ui.cjs`：阅读恢复、抽屉隔离及焦点、切换请求竞争、慢请求反馈、Source 图标与状态保持、Reduced Motion。
- `tests/footnotes.cjs`：悬停延迟、取消、进入卡片、复用、固定、焦点恢复与换页清理。
- `tests/frontend.cjs`：Markdown / 数学 / 中文目录及按需加载图表引擎。
- `tests/admin_ui.py`：管理员权限、密码重设 / 移除、旧访问撤销、日期验证、过期表单、链接冲突、旧归属数据及转义。
- 浏览器在 320 / 390 / 1280px 下检查阅读及后台布局；对 Source / Preview 往返三次以及 PDF 弹窗开关测量，正文、阅读框与工具栏横向位置差均为 0px。
- 短脚注样例从原先固定的 360×400px 收敛为约 400×117px，实际高度随内容变化。
- 打包检查通过；配置、数据库和上传文件不会进入分发包。

静态体积对比：三份样式 / 脚本合计 gzip 增加 4,858 bytes；默认系统字体不再请求 34,324 bytes 的 Latin 字体。此数字是文件压缩对比，不代表生产网络、Lighthouse 分数或帧率测量。

## 2026-10-28 统一完善

- 欢迎页 Continue reading 使用完整内边距；Browse documents 展开并聚焦文档树。层级使用细连接线与叶节点圆点，保留笔记图标。
- 分享列表列出全部筛选结果，内容区 960px 起三列卡片，620px 起双列，窄屏单列；网站设置按存储、阅读与链接、外观、PDF 和插件连接分组。
- 网站与插件从同一份 controls.js / controls.css 打包下拉菜单和日期面板，支持键盘操作、手动日期输入和销毁清理；无 JS 时使用原表单。
- 分享访客上限、统计、历史表与数据库字段退役；旧请求字段忽略。PDF 配额与防滥用身份独立保留。
- 滚动条、复选框、单选框和确认对话框统一；反馈 140ms、内容变化 220ms、按压 100ms，支持 Reduced Motion。

本轮验证：PHP 8.3.36 下 60 项运行检查；59 项 HTTP / PDF 回归中 58 项通过，仅 Nginx 规则留待真实 Docker CI。包含浏览器 PDF 下载与长文档导出。五种屏宽 × 明暗两主题下检查全量 14 条分享、菜单、日期面板及 Browse 焦点，无横向溢出。部署模拟保护、插件生命周期与缓存迁移、共用控件键盘交互、阅读器、脚注、Markdown 和打包检查通过。

## 文档树与密度修正

- 文档名统一单行省略；父节点箭头、叶节点圆点与分支线共用行高、缩进和中心坐标，触屏使用 44px 行高。
- 桌面侧栏分隔线支持拖动、方向键微调和 Enter / 双击恢复默认。宽度为 220–640px，并为正文保留至少 360px；cookie 保存一年，服务端首屏恢复，手机抽屉保持独立宽度。
- 分享卡片的文件大小与标题同区，管理操作与访问状态同排；三列布局减少独立按钮行的空白。
- 标签与标题加粗，表单值和下拉框选中值明确使用常规字重。
