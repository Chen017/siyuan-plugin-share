# 阅读与个人后台界面规范

本文记录当前界面的行为与维护约束，安装与操作见根目录 README，工程结构和命令见 [维护指南](MAINTENANCE.md)，PDF 的权限、额度与生成规则见 [PDF 文档](GUEST_PDF_EXPORT.md)。具体测试结果以对应提交的 CI 和本地日志为准。

## 视觉、语言与动效

- 网站使用英文和 SiYuan Share 站名；仅归一化两个旧默认中文站名，保留其他自定义名称。插件语言包和笔记内容独立。
- 复用系统字体、中性色表面、蓝色主操作及现有卡片、按钮和表单组件。保持中文、English、数学和代码各自的排版规则，不为单个面板添加固定浅色背景或另起一套操作颜色。
- 画布、正文、侧栏、浮层和输入区使用语义颜色。主题别名在各页面 `body` 上解析，跟随该页面的实际基础颜色；避免从 `:root` 继承已经解析的浅色值。危险操作、输入和 PDF 内外层控件在明暗主题下均须可读。
- 统一工具图标尺寸，保留自定义文档图标和 emoji。粗指针下按钮至少 44px；320px 窄屏不得产生页面横向溢出。
- 动效服务于反馈和理解，参考 [Apple Motion 指南](https://developer.apple.com/design/human-interface-guidelines/motion)。项目使用短反馈、内容切换和按压过渡；面板文字保持不透明，以位移和独立遮罩表现进退场。CSS 与 JavaScript 都尊重 Reduced Motion。
- 首次正文直接显示；不增加持续帧循环、滚动视差或单独的动画依赖。过渡被新操作打断时应正确取消和恢复状态。

## 阅读与导航

- Markdown 六级标题保持明确层次；阅读页与 PDF 共用层级。手机阅读页单独调整 H2/H3 行高和章节间距，不把后置规则作用于 PDF。
- 欢迎页始终以 Browse documents 为主操作，展开并聚焦文档树；本地 Continue reading 保持次要入口。
- 文档树标题单行省略，目录的长标题在手机内完整换行。树的行高、箭头、叶节点圆点和分支线共享坐标；分组配色与吸顶规则见维护指南。
- 桌面侧栏可拖动、用方向键调整，以 Enter 或双击恢复默认；最大 640px，并为正文保留至少 360px。最小宽度依据工具栏实际尺寸计算，再向左拖过 24px 可收起。Navigation、Browse 和 Ctrl/Cmd+K 可重新展开。
- 展开宽度和收起状态分别保存到 cookie，服务端首屏恢复；手机抽屉使用独立宽度。桌面侧栏上下各留 24px，底部条目保持可达。
- 树和目录的内部自动定位使用即时滚动。同一文档只初次定位一次，延后加载不得覆盖用户手动滚动；手动滚动目录后暂停自动跟随，直到再次操作正文。目录选中只更新前后两个条目。
- 文档切换只过渡变化区域；慢请求在 250ms 后显示反馈，快请求不闪动加载条。Source / Preview 按钮宽度稳定，页面预留根滚动条空间，弹窗不额外创建根滚动区。
- 手机目录关闭背景隔离后再聚焦目标标题。受保护分享使用独立密码标签、关联错误和显示/隐藏按钮。
- 搜索先处理完整数学边界，再截取匹配附近的普通文字；公式和旧响应回退使用 Formula / Image 描述，不暴露残缺公式片段。

## 脚注、数学与图片

- 脚注悬停 350ms 后打开、离开 240ms 后关闭；可移入、点击保留或固定，短内容按自然高度展示。Escape、导航和滚动会取消预览；键盘关闭恢复焦点。
- 数学 token 的可信 KaTeX 输出在普通 HTML 清理后挂载；任意原始 MathML 继续过滤，生成器关闭 `trust`。占位标识兼容非安全上下文的 `getRandomValues`；不依赖 DOM 选择器组合返回顺序来确定图片焦点顺序。
- 图片查看器支持键盘入口、模态语义、背景 `inert` 恢复及关闭后的焦点返回。关闭入口固定右上，旋转放入 More；缩略图提供名称和选中状态。
- 图片尺寸、SVG 背景和附件访问保护沿用维护及上传指南；界面重构不得绕过授权或重写原文件颜色。

## 个人后台与共享控件

- 导航位于顶部；用户名用普通文本，退出使用统一按钮。日常分享卡片展示标题、大小、访问状态、到期时间和管理操作，小屏单列。
- `Delete` 是可恢复删除，直接执行后提供带标题的 Undo；永久删除始终确认目标和不可恢复后果，通知由用户主动关闭。
- 分享编辑器提供标题、链接后缀、到期、密码重设和移除保护；空到期时间表示永不过期。密码仅保存 hash，不回显旧密码，新输入可显示/隐藏。
- 后台与插件复用 `save_share_access()` 和链接校验，版本检查拒绝过期表单；旧同步不得覆盖较新的访问设置，编辑访问设置不改变内容归属。
- 网站设置仅在实际编辑后提醒离开；显式 Cancel 放弃编辑。密码和表单草稿不存储到浏览器。插件连接设置在 Site settings 的折叠区域，日常列表不展示 API key 管理。
- 下拉和日期面板使用网站与插件共用的 `controls.js` / `controls.css`，支持键盘、手动日期输入和销毁清理；无 JS 时保留原表单。320px 触屏日历贴边容纳七列。

## PDF 与图片优化面板

- PDF 在手机使用底部面板、桌面使用居中对话框；选项区只有一个主要纵向滚动区，标题和操作保持可见。按实际内容自适应高度，达到上限后仅内容滚动；Reduced Motion 下即时调整。
- 范围筛选保留隐藏选择，Clear selection 清空全部；计数区分所选数量和批次上限。脚本未就绪前禁用 Export，iframe 加载时提供反馈；运行中关闭、Escape 和遮罩操作使用一致的取消确认规则，已下载文件保留。额度细节以 PDF 文档为准。
- 图片优化面板复用现有样式，区分总数、实际变小、待检查和节省空间；不把已检查/跳过称为已压缩，不承诺感知无损。工具能力放入可键盘展开的说明。
- 后台任务使用具名 `progress` 和 live status，停止保留已完成结果。状态请求串行、隐藏页暂停、超时重试并显示连接异常；完成后原位置更新状态，不刷新正在编辑的页面，状态 JSON 禁止缓存。

## 验证入口与边界

| 范围 | 现有入口 |
| --- | --- |
| Markdown、数学语义、图片键盘、异步图表和图片任务轮询 | `tests/frontend.cjs`、`tests/render-security.cjs` |
| 阅读恢复、侧栏、抽屉、导航竞争与搜索 | `tests/reader-ui.cjs` |
| 脚注生命周期与布局 | `tests/footnotes.cjs` |
| PDF 选择、计数和取消状态 | `tests/pdf-ui.cjs`、`tests/pdf-browser.cjs`、PHP PDF 用例 |
| 后台权限、编辑版本、Undo、配置与自动图片优化 | `tests/admin_ui.py`，由 `tests/run.py` 执行 |
| 网站/插件共用控件 | `tests/controls.cjs`、`tests/plugin.cjs`、`tests/package.py` |
| 标题、树、图片尺寸与主题 | `tests/browser-ui.py`、`tests/heading-spacing.cjs`、`tests/tree-groups.cjs`、`tests/image-sizing.cjs` |
| 真实 UI 组合验收 | `tests/ui-refinement-browser.cjs`，由 `tests/run.py --browser` 的 PDF 浏览器用例调用 |

真实 UI 验收覆盖明暗主题 × 320/390/768/1280px、图片焦点、PDF 单滚动区、触控日历、对比度、高对比、文字缩放和未保存提醒。共享 CSS 改动后须重建 `reader-style.css`；插件包从同一份服务端源文件取共享 controls，不复制维护第二份实现。

Edge 的内部 downloads-hub 可能表现为空 Page URL。无额外应用标签页的断言通过浏览器级 CDP 查询真实目标，只排除同上下文中真实 `edge://` / `chrome://` 内部目标，未知空白页仍计入。

自动测试不替代真实 iOS/Android、VoiceOver/TalkBack 朗读、设备上的主观动效和帧率/耗电测量；浏览器扩展与任意管理员自定义样式组合也需单独验证。测试日志和阶段性交付结果不作为长期产品规范重复保存。
